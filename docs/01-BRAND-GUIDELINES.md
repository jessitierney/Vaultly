# Vaultly Brand Guidelines

## Mission

"Enter information once. Let Vaultly do the rest."

Vaultly is a premium Household Operating System that organises every aspect of home, finances, projects, documents, maintenance and family life from one connected platform.

## What Vaultly Is

- Household operating system
- Information organisation platform
- Document management system
- Project coordination hub
- Financial tracking and forecasting
- Family communication centre
- Household automation engine

## What Vaultly Is NOT

- Budgeting app
- Financial advisory service
- Legal advisory service
- Tax advisory service
- Investment recommendation engine
- Bill payment system
- Money transfer service
- Financial decision recommendation engine

## Tone & Language

Use neutral, empowering language:

- Track (not "monitor" or "spy on")
- Organise (not "manage" or "control")
- Forecast (not "predict" or "guess")
- Summarise (not "report" or "analyse")
- Link (not "connect" or "sync")
- Monitor (not "oversee" or "track")
- Remind (not "alert" or "notify")
- Surface (not "display" or "show")

## Core Values

- **Calm:** Serene, unhurried, stress-free
- **Premium:** High-quality, thoughtful, sophisticated
- **Connected:** Intelligent linking, no duplication
- **Effortless:** Simple, intuitive, automated
- **Trustworthy:** Secure, private, reliable

## Visual Identity

### Colour Palette

| Colour | Hex | Usage |
|--------|-----|-------|
| Warm Cream | #F6F2EA | Primary background |
| Soft Slate Navy | #38506A | Primary text, key elements |
| Sage | #A4B69A | Accents, secondary elements |
| Mustard | #E0B14D | Highlights, CTAs |
| Terracotta | #C86B4A | Alerts, warnings |

### Typography

- **Headings:** Oswald SemiCondensed (60-80px)
- **Subheadings:** Oswald SemiCondensed (24-32px)
- **Body:** Montserrat (14-18px)
- **Small text:** Montserrat (12-14px)

### Design Elements

- Rounded cards (20-32px border radius)
- Subtle shadows (0 18px 60px -24px rgba(36,56,77,0.26))
- Generous whitespace
- Premium spacing (8pt grid system)
- Thin outline icons
- Cream/white backgrounds
- Soft earthy colour palette

### Logo

Use the house-and-lock logo throughout:
- Navigation bars
- Header
- Authentication pages
- Loading screens
- Favicon

## Never Change

- Brand colours
- Typography system
- Design system principles
- Logo usage
- Core mission statement

All future designs must align with these guidelines.
